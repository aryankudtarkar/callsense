# References

Research and environment snapshot accessed on **24 October 2026**, unless the source is a versioned publication. The sources below support technical and factual claims in the research documents; legal materials should be checked again before any deployment.

- **[R1]** Adham Ibrahim, Shady Shehata, Ajinkya Kulkarni, Mukhtar Mohamed, Muhammad Abdul-Mageed. “What Does it Take to Generalize SER Model Across Datasets? A Comprehensive Benchmark.” Interspeech 2024, DOI 10.21437/Interspeech.2024-1983. [Paper PDF](https://www.isca-archive.org/interspeech_2024/ibrahim24_interspeech.pdf). Cross-dataset evaluation across eleven corpora; supports domain-shift, speaker, recording, elicitation, and evaluation claims.
- **[R2]** Shu-wen Yang et al. “SUPERB: Speech processing Universal PERformance Benchmark.” Interspeech 2021 / arXiv:2105.01051. [ISCA paper](https://www.isca-archive.org/interspeech_2021/yang21c_interspeech.pdf), [official Meta research page](https://ai.meta.com/research/publications/superb-speech-processing-universal-performance-benchmark/). Supports self-supervised speech representation and task-specific head context.
- **[R3]** Hugging Face, `superb/wav2vec2-base-superb-er`, model card, config and preprocessor files. [Model card](https://huggingface.co/superb/wav2vec2-base-superb-er), [config](https://huggingface.co/superb/wav2vec2-base-superb-er/raw/main/config.json), [preprocessor](https://huggingface.co/superb/wav2vec2-base-superb-er/raw/main/preprocessor_config.json). Supports four labels, English, 16 kHz, 378 MB, model card accuracy table, and direct Transformers inference. The live `main` references here were not pinned; implementation must choose an immutable revision.
- **[R4]** Hugging Face Transformers, “Feature extractors.” [Official docs](https://huggingface.co/docs/transformers/feature_extractors). Supports matching waveform sample rate to model preprocessor and use of feature extractors.
- **[R5]** SpeechBrain, `speechbrain/emotion-recognition-wav2vec2-IEMOCAP`, model card and custom interface. [Model card](https://huggingface.co/speechbrain/emotion-recognition-wav2vec2-IEMOCAP), [inference interface](https://huggingface.co/speechbrain/emotion-recognition-wav2vec2-IEMOCAP/raw/main/custom_interface.py). Supports alternative labels, 16 kHz input, custom interface, reported test score, and cross-dataset limitation warning.
- **[R6]** audEERING, `wav2vec2-large-robust-12-ft-emotion-msp-dim`. [Model card](https://huggingface.co/audeering/wav2vec2-large-robust-12-ft-emotion-msp-dim), [license](https://huggingface.co/audeering/wav2vec2-large-robust-12-ft-emotion-msp-dim/blob/main/LICENSE). Supports valence/arousal/dominance output and CC BY-NC-SA 4.0 terms.
- **[R7]** emotion2vec, `emotion2vec_plus_large`. [Model card](https://huggingface.co/emotion2vec/emotion2vec_plus_large). Supports the listed nine labels, approximate model size, and `model-license` metadata; the metadata is not treated as a standard open license.
- **[R27]** FunASR, “FunASR Model Open Source License Agreement v1.1.” [License text](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE). Requires source/author attribution and retention of model names; describes reference/learning use and places responsibility for use on the user.
- **[R8]** Livingstone and Russo. “The Ryerson Audio-Visual Database of Emotional Speech and Song (RAVDESS): A dynamic, multimodal set of facial and vocal expressions in North American English.” PLoS ONE 13(5), 2018, e0196391.
